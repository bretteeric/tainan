為什麼要學

不是你不夠聰明，是沒有人帶你走完第一次

AI 的資訊不缺，缺的是「從看懂到做出來」這一段路有人陪著走。 短影片教你按下一個按鈕，養成班陪你把它變成自己的東西。 如果你卡在下面任何一句，這門課就是為你設計的。

講很多，做不出來

影片看了十幾支，關掉螢幕還是不知道第一步要打什麼。

工具太多，選不完

ChatGPT、Claude、各種套件與模型，換過一輪，還是沒做完一件事。

想用，卻不知從何開始

心裡有想法，但沒人陪你走過第一個「真的能用」的版本。

錯誤訊息就是一道牆

邏輯不難，但紅色錯誤訊息一出現，就只能放棄。

六大模組

六個模組、120 小時，一路堆到你做得出來

模組一到模組六是同一條線：先把環境與語法打穩，再練資料處理， 接著做生成式 AI 應用、訓練模型、實作影像辨識，最後用專題把所學收成一個成品。 每個觀念後面都接著一段你自己動手的時間。

模組一 18 小時

程式設計與環境基礎

從零開始：語法、開發環境、版本控制

  • Python 語法與資料結構：變數、串列、字典、條件與迴圈
  • 函式與模組：把重複的動作包成可以一用再用的程式
  • 開發環境：VS Code ＋ venv ＋ 套件管理，自己裝得起環境
  • Git 版本控制：commit、分支，以及怎麼回到上一個能跑的版本
  • 檔案讀寫、API 呼叫與 JSON：讓程式跟外面的服務交換資料

你會做出一支在終端機執行、能讀檔也能呼叫 API 的命令列小工具

模組二 18 小時

Python 資料處理與視覺化

把散落的表格，變成說得出結論的報表

  • pandas 資料清理：缺值、重複、格式不一致怎麼處理
  • 篩選、分組與樞紐分析：從幾萬筆資料裡問出你要的答案
  • matplotlib 圖表：用一張圖把一堆數字講成一句話
  • Excel／CSV 自動化報表：每月固定要做的整理交給程式
  • 從原始資料到結論的完整流程演練

你會做出一份換上本月資料就能重跑的 Excel 分析報表

模組三 30 小時

生成式 AI 應用開發

全期最重的一段：從呼叫 API 到做出自己的 AI 小助手

  • LLM 與 API 基礎：Token、費用、速率限制與成本估算
  • Prompt 設計與結構化輸出：讓模型穩定吐出你要的 JSON
  • RAG 知識庫問答：把手上的文件變成可以問的知識庫
  • AI Agent 與工具呼叫（function calling）：讓模型會動手做事
  • 串接網頁／LINE 的 AI 小助手：真的能給同事或客戶用

你會做出一個能問你自己文件、接得上網頁或 LINE 的 AI 小助手

模組四 18 小時

機器學習與模型訓練基礎

從資料到模型，再到一支別人叫得動的服務

  • 資料前處理與特徵工程：哪些欄位有用、怎麼變成模型吃得下的數字
  • 迴歸與分類模型：預測數字、判斷類別，差別在哪裡
  • 評估指標：準確率不夠看，還要知道模型錯在哪
  • 過擬合、交叉驗證與調參：為什麼訓練很準、上線就爛
  • 模型打包成 API：把模型變成別的程式叫得動的服務

你會做出一個用 HTTP 就能呼叫的預測模型服務

模組五 24 小時

AI 影像辨識實作

讓程式長出眼睛：從讀像素到認出目標物

  • OpenCV 影像處理：讀圖、縮放、濾波、畫框與標註
  • CNN 概念與預訓練模型：用遷移學習省下從零訓練的時間
  • YOLO 物件偵測與資料標註：自己標一批資料、訓練一個偵測器
  • 分類／偵測專題實作：把辨識結果接成通知、紀錄或警示

你會做出一支丟進照片就能框出目標物的影像辨識程式

模組六 12 小時

專題實作與成果發表

把六個模組收成一個能拿出去講的成品

  • 題目定義與需求訪談：從你工作上真的痛的地方找題目
  • 分組開發與技術輔導：真的動手做，卡住的時候有人在旁邊
  • 成果發表與文件撰寫：講清楚做了什麼、怎麼做、能解決什麼

你會做出一個可展示的專題成品，加上一份講得清楚的成果簡報

你會做出什麼

六個模組，各留下一件成品

不是講義上的範例，是你親手做完、可以繼續改、可以拿去給同事看的東西。 最後收成一個專題，能直接拿去發表。

01

一支命令列小工具

在終端機就能跑：讀檔、整理資料、呼叫 API、把結果印出來，模組一結束就有一支。

02

一份自動產出的分析報表

換上本月資料就能重跑的 Excel 報表與圖表，原本半天的手工整理變幾秒鐘。

03

一個能問自己文件的 AI 小助手

接上大型語言模型與你自己的文件，限定在你關心的主題回答，還能接到網頁或 LINE。

04

一個可呼叫的預測模型 API

自己訓練的模型包成服務，別的程式只要發一個請求就能拿到預測結果。

05

一支看得懂照片的影像程式

丟一張圖進去，回傳它辨識到什麼、框在哪裡，可以換成你自己的照片測試。

06

一個專題成果＋簡報

從題目定義做到成果發表，一個能拿去給主管、客戶或投件看的完整作品。

適合對象

誰適合來上

  • 想讓 AI 真的幫上工作，而不只是聊天的人
  • 非資訊背景、沒寫過程式也歡迎——模組一從零基礎開始
  • 需要自己做小工具、不想每次求工程師的實務工作者
  • 想帶回公司落地使用，甚至帶一個小團隊做 AI 的部門主管與專案負責人

先備條件

  • 不需具備程式底子。模組一從最基本的語法與環境講起。
  • 需自備筆電（Windows 或 macOS 皆可，需可連網）。
  • 需能投入 120 小時、全程參與。這是一段養成，不是聽一場演講。
  • 會基本檔案操作、能收發 Email 即可。

課前會提供一份安裝清單，照著做就能把環境準備好；請假與補課方式見常見問題。

常見問題

報名前，你可能想問

需要自己帶筆電嗎？

需要。Windows 或 macOS 皆可，重點是要能連網。課程使用的工具都是免費的，課前會提供安裝清單，照著做就能完成環境準備。

完全沒有程式基礎可以上嗎？

可以。模組一從最基本的語法、資料結構與開發環境開始，用生活化的例子講，不需要先會任何語言。120 小時的安排裡，前面打底的時間是留得下來的；有基礎的人會在後面的生成式 AI、機器學習與影像辨識拿到更多，但這些不會被預設為必要條件。

120 小時上得完嗎？請假怎麼辦？

這 120 小時是排進六個模組裡的扎實時數，不是把幾天課取個好聽的名字。上班族要跟完，前提是把這段時間先排出來；報名前請先確認排得出來。

真的有事請假，請於課前通知課程窗口，補課與教材領取方式依主辦單位規定辦理：{{待補：缺課補課規定}}。提醒一句：模組是疊上去的，缺一堂實作課，後面的進度會比較辛苦，建議缺課不要超過一個模組。

和坊間 6 小時工作坊差在哪？

6 小時工作坊的價值是讓你看到 AI 能做什麼；養成班要讓你做得出來。差別在實作時間與責任：120 小時裡有大量你自己動手的時段，從環境安裝、資料處理、API 串接、模型訓練到影像辨識，每一段都要交出東西；最後還有專題，你得自己定義題目、做完、講給別人聽。

上完工作坊，你多半會回去繼續用現成工具；上完這門課，你手上會有一組自己寫的程式，和一套遇到新問題知道怎麼拆、怎麼查、怎麼做完的方法。
