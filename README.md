# AI 程式設計與影像辨識實戰班｜招生頁

臺南大學 2026 年 11–12 月開課的單頁式招生網站。純靜態（HTML／CSS／JS），零建置、無框架、無 CDN、無外部字型，資料夾直接丟上 GitHub Pages 就能跑。

## 檔案結構

```
<專案根目錄>/
├── index.html              單頁招生頁（錨點分區）
├── assets/
│   ├── css/style.css       全部樣式（純手寫，含響應式斷點）
│   └── js/main.js          原生 JS：手機選單、平滑捲動、FAQ、進場動畫
├── tools/check_trad.py     簡體字檢查腳本（交付前跑一次）
└── README.md               本檔
```

沒有 `assets/img/`：頁面上的圖示、背景網格、光暈全部是 inline SVG 或 CSS 產生，沒有任何外部圖檔依賴。

## 本機預覽

```bash
cd tainan
python3 -m http.server 8099
# 開 http://127.0.0.1:8099/
```

直接雙擊 `index.html` 也可以（`file://`），只是錨點與快取行為以本機伺服器較接近線上。

檢查有沒有簡體字（有命中會 exit 1）：

```bash
python3 tools/check_trad.py
```

## 部署到 GitHub Pages

1. 建立 repo，把 `tainan/` 裡的內容放到 repo 根目錄（或放 `docs/`）。
2. Settings → Pages → Source 選 `Deploy from a branch`，分支 `main`、資料夾 `/ (root)`（或 `/docs`）。
3. 等 1–2 分鐘，網址會是 `https://<帳號>.github.io/<repo>/`。
4. 若要放自訂網域，在 repo 根目錄加 `CNAME`。

注意：`index.html` 內的 `og:url`／`og:image` 目前沒有填（沒有固定網址與品牌圖），上線後建議補成正式網址。

## 怎麼改文案

全部文案都在 `index.html`，區塊順序與錨點：

| 錨點 | 區塊 | 主要內容 |
| --- | --- | --- |
| `#top` | Hero | 課名、一句話主張、42 小時／3 門課／7 個上課日／每日 09:00–16:00、兩個 CTA |
| `#why` | 為什麼要學 | 4 張痛點卡片 |
| `#modules` | 課程三模組 | 原理 12H／應用 21H／影像辨識 9H，各列學習重點 |
| `#outcomes` | 你會做出什麼 | 5 個課後成品 |
| `#audience` | 適合對象／先備條件、講師 | 誰適合、需自備筆電、陳宗興老師 |
| `#schedule` | 上課資訊 | 7 個上課日表格（手機轉卡片）＋ 上課時間／地點／人數／學費 |
| `#enroll` | 報名流程 | 3 步驟＋注意事項 |
| `#faq` | 常見問題 | 6 題（`<details>` 手風琴，無 JS 也可展開） |
| footer | 頁尾 | 聯絡方式、主辦單位 |

改顏色與圓角：`assets/css/style.css` 最上面的 `:root` 變數（`--accent`、`--bg`、`--radius` 等）。
改課程日期：`#schedule` 表格的 `<tbody>`，以及 Hero 的「上課期間」；手機版卡片標題是用 `data-label` 產生的，改表格時一起確認。
改字級／間距：`style.css` 內的區塊註解分得很細，直接搜註解標題最快。

## 待補欄位清單（上線前務必填掉）

頁面上所有未知資訊都用 `{{待補：…}}` 佔位，直接搜 `{{待補` 就能全部找到（共 10 種）：

| 待補欄位 | 出現位置 |
| --- | --- |
| `{{待補：教室}}` | Hero 上課期間那行、上課資訊卡、報名流程第 3 步 |
| `{{待補：學費}}` | 上課資訊卡、FAQ「費用怎麼算」 |
| `{{待補：繳費方式}}` | 上課資訊卡、報名流程第 3 步、FAQ「費用怎麼算」 |
| `{{待補：名額}}` | 上課資訊卡（人數上限） |
| `{{待補：報名表單網址}}` | 報名流程第 1 步（目前是文字佔位，不是假連結） |
| `{{待補：電話}}` | 頁尾、報名流程注意事項、FAQ「費用怎麼算」 |
| `{{待補：Email}}` | 頁尾、報名流程注意事項 |
| `{{待補：主辦單位}}` | 頁尾 |
| `{{待補：缺課補課規定}}` | FAQ「缺課怎麼辦」 |
| `{{待補：教材形式與提供方式}}` | FAQ「會不會給教材」 |

原則：寧可留 `{{待補：…}}`，也不要自己編數字、編電話或放假連結。填完後 `{{待補` 應該搜不到任何一筆。
